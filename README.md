# CSC-436_Projects
Repository for all six CSC - 436 projects for Fall 2026

## Project 1: College of Staten Island's Video Game Development Club Website:
Due: September 15th, 2026

Description:
    This project is a website for CSI's Video Game Dvelopment club. It includes information about the club,
its mission, its current leaders, and links to Discord and CSI Connect. It is also responsive to different
screen sizes and includes JavaScript interactivity.

How to Run Locally:
    1. Download or clone the repository onto your computer.
    2. Make sure the following files are located in the Project 1 folder:
        - index.html
        - about.html
        - style.css
        - script.js
        - background.svg
    3. Open the project folder in a code editor (like Visual Studio Code)
    4. Open index.html in a web browser

The Live Server extension for VSC is recommended for an easier experience!

Live Website:
    https://chrisvsanchez.netlify.app

## Project 2: A React Game by Chris Sanchez
Due: October 11th, 2026

Description:
    This project is a small Idle Game made using React. I made this game to challenge my understanding
of React fundamentals while trying to make something unique at the same time. The main gameplay loop is
to generate items while idling and to use those items to create others that require them. I plan to add
more features like money, experience, and multi-item recipes in the future.

How to Run Locally:
    1. Download or clone the repository onto your computer.
    2. Make sure the following folders and their respective files are located in the Project 2 folder:
        - src
            - Assets
            - Components
    3. Open the project folder in a code editor (like Visual Studio Code)
    4. Change directory to Project 2: cd CSC-436_Projects/"Project 2"
    5. Run the terminal command: npm run dev and follow the link to http://localhost:5173
